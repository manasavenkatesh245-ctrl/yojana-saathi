# 🇮🇳 Yojana Saathi – AI Government Scheme Assistant

## 📌 Project Overview

Yojana Saathi is an AI-powered web application designed to help Indian citizens discover government welfare schemes that may be relevant to their needs. It helps users understand eligibility requirements, identify potentially suitable schemes, learn about required documents, and prepare for the application process.

The goal of this project is to make government scheme information easier to access and understand through a simple, user-friendly interface.

## 🎯 Objectives

- Help citizens discover relevant government welfare schemes.
- Simplify eligibility criteria and scheme information.
- Reduce confusion when searching for government benefits.
- Provide guidance on documents and application procedures.
- Improve accessibility through supported languages and input methods.

## ✨ Key Features

- **Scheme Discovery:** Explore potentially relevant government schemes.
- **Eligibility Guidance:** Understand scheme requirements and possible eligibility.
- **AI Assistance:** Ask questions and receive guidance through the application's AI functionality.
- **Document Assistance:** Use supported document-processing features to extract relevant information.
- **Multilingual Interaction:** Access supported language options.
- **Application Guidance:** Learn about application steps and required documents.
- **Responsive Design:** Use the application on compatible desktop and mobile browsers.

*Feature availability depends on the current implementation and configuration.*

## ⚙️ How to Run the Project

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/manasavenkatesh245-ctrl/yojana-saathi.git
```

Navigate to the project directory:

```bash
cd yojana-saathi
```

Install dependencies:

```bash
npm install
```

Configure the required environment variables in `.env.local` if needed.

Start the development server:

```bash
npm run dev
```

Open the application at:

http://localhost:3000

## ☁️ Deployment

This project can be deployed using Vercel. Import the GitHub repository, configure any required environment variables, and deploy using the project's Next.js settings.

**Live Demo:** https://yojana-saathi-pi.vercel.app/
